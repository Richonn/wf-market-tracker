# Governance

wf-market-tracker is a personal project maintained by [@Richonn](https://github.com/Richonn).

## Decision making

All architectural decisions are documented in [DECISIONS.md](DECISIONS.md). The maintainer has final say on all changes.

Pull requests are welcome. There is no formal review process — PRs that pass CI and align with the project goals will be merged at the maintainer's discretion.

## Roadmap

The project evolves based on personal use. There are no commitments on timelines or features.
